# College Complaint Management System

A Flask + MySQL web application for managing student complaints,
using genuine Data Structures (Queue, Stack, Linked List).

## Tech Stack

- **Backend:** Python 3, Flask
- **Database:** MySQL 8 (Aiven Cloud)
- **Frontend:** HTML5, CSS3, Jinja2
- **Data Structures:** Queue (FIFO), Stack (LIFO), Singly Linked List
- **Algorithms:** Linear Search, Bubble Sort

## Features

- **Student:** Submit complaints, track by ID, view history
- **Admin:** Dashboard, FIFO processing, search, sort, update, undo
- **Inspector:** Read-only access with dashboard
- **Anonymity:** Complaints hidden from staff, visible to students
- **Reports:** Category graphs, class graphs, status distribution
